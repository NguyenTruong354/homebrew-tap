# Homebrew tap

[Homebrew](https://brew.sh) formulae for [live-serve](https://github.com/NguyenTruong354/live-serve), on macOS (Apple Silicon and Intel) and Linux (x86_64 and Arm64; static binaries, so any distribution).

```
brew install nguyentruong354/tap/live-serve
```

Upgrade with `brew upgrade live-serve`.
